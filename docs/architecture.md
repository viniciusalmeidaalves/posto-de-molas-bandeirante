# Arquitetura do projeto

Este repositório é um site estático sem backend, banco de dados ou processo de build.

## Visão geral

A aplicação é composta por páginas HTML independentes, estilizadas com CSS e enriquecidas com JavaScript simples para interações básicas.

## Componentes principais

- Páginas HTML: conteúdo institucional e navegação
- CSS: estilos compartilhados e layout responsivo
- JavaScript: comportamento de interface e navegação
- Assets estáticos: imagens, áudio e ícones

## Fluxo de uso

1. O usuário acessa a página inicial.
2. Navega pelas páginas institucionais por meio do menu.
3. O conteúdo é exibido diretamente no navegador sem necessidade de servidor de aplicação.
