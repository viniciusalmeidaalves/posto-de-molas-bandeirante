# Instalação e execução

Este projeto não exige instalação de dependências, compilação ou configuração de banco de dados. Trata-se de um site estático.

## Requisitos

- Navegador moderno
- Arquivos do repositório baixados localmente

## Execução local

1. Clone o repositório.
2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Como alternativa, sirva a pasta raiz com qualquer servidor HTTP estático e acesse a URL local fornecida por ele. Essa opção representa melhor o comportamento de uma hospedagem web do que abrir o arquivo diretamente.

## Publicação

Para publicação em ambiente web, o projeto pode ser servido por qualquer hospedagem estática. O arquivo `htaccess` é aplicável a servidores Apache e contém a regra de redirecionamento da porta 80 para HTTPS.
