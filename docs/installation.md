# Instalação e execução

Este projeto não exige instalação de dependências para funcionar.

## Requisitos

- Navegador moderno
- Arquivos do repositório baixados localmente

## Passos

1. Clone o repositório.
2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

## Observação

Para publicação em ambiente web, o projeto pode ser servido por qualquer hospedagem estática.
