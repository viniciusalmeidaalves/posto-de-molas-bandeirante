# Tecnologias

## Linguagens

- HTML5
- CSS3
- JavaScript

## Recursos e integrações

- Font Awesome 6.5.0 para ícones, carregado por CDN
- HTML5 Audio para reprodução da vinheta institucional
- Arquivos de mídia locais em formatos como AVIF, imagens raster e MP3
- Apache `htaccess` para o redirecionamento HTTP para HTTPS

## Observações

Não há backend, banco de dados, framework JavaScript moderno, gerenciador de dependências, build system, testes automatizados ou pipeline de CI/CD no repositório atual.
