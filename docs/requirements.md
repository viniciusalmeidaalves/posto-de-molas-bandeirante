# Requisitos do projeto

## Requisitos funcionais

- Apresentar informações institucionais da empresa
- Exibir páginas de serviços, estrutura e contato
- Disponibilizar navegação entre páginas
- Exibir conteúdo visual com imagens e áudio

## Requisitos técnicos

- Navegador compatível com HTML5, CSS3 e JavaScript
- Acesso a arquivos estáticos locais
- Hospedagem estática ou servidor simples para visualização web
