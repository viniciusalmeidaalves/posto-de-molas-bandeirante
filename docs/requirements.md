# Requisitos do projeto

## Escopo

O projeto atende à apresentação institucional do Posto de Molas Bandeirante, seus serviços, estrutura e canais de contato por meio de páginas estáticas.

## Requisitos funcionais

- Apresentar informações institucionais da empresa
- Exibir páginas de serviços, estrutura e contato
- Disponibilizar navegação entre páginas
- Exibir conteúdo visual com imagens e áudio
- Disponibilizar página de privacidade e sitemap
- Apresentar links para redes sociais e formas de contato

## Requisitos técnicos

- Navegador compatível com HTML5, CSS3 e JavaScript
- Acesso aos arquivos estáticos locais e à CDN do Font Awesome quando os ícones forem carregados externamente
- Hospedagem estática ou servidor HTTP simples para visualização web

## Restrições conhecidas

- Não há backend, banco de dados, autenticação ou API no repositório.
- Não há gerenciador de dependências, processo de build ou testes automatizados configurados.
